Frequently Asked Questions & Technical Support

Everything you need to know about security, blueprints, and data integrity

How does GridSnag guarantee zero data egress?

GridSnag is built strictly with zero network entitlements and zero external network calls. All drawings, photos, voice models, and punch items are stored within Apple's local encrypted sandbox. You can verify this by running the app in Airplane Mode or using network monitoring tools.

What blueprint formats are supported?

GridSnag supports vector and raster PDF blueprints exported directly from AutoCAD, Revit, ArchiCAD, and MicroStation. Vector blueprints support up to 1000% lossless zoom. Furthermore, you can use the built-in Interactive Structural Grid mode without any blueprint files.

Does GridSnag require an account or subscription?

No account, registration, or subscription is required. Download once and use it permanently across iPhone, iPad, and Mac under Apple's Universal Purchase.
